# Ручное тестирование (шаблон чек‑листа)

Этот чек‑лист дополняет автопрогон `selen/main.py`. Идея: автотесты ловят регрессию по “сквозным” сценариям, а ручная проверка закрывает UX, тексты, пограничные кейсы и визуальные дефекты.

## Как работать

- **Договориться о наборе**: smoke (быстро) / regression (стенд перед сдачей) / full (перед релизом).
- **Фиксировать артефакты**: скриншот/видео, шаги, ожидаемое/фактическое, окружение (URL, браузер, роль).
- **Повторяемость**: если баг “плавающий” — обязательно отметить частоту (1/10, 3/10) и условия.

## Smoke (5–10 минут)

- **Доступность**: сайт открывается, нет 500/белой страницы.
- **Логин**: вход админом успешен; неверный пароль даёт понятную ошибку.
- **Навигация**: страницы “Заказы/Клиенты/Комплектующие/Категории/Зоны доставки/Гарантии” открываются без критических ошибок.
- **CRUD минимально**:
  - **Категории**: добавить категорию, убедиться что появилась в списке.
  - **Клиенты**: добавить клиента, убедиться что появился в списке/поиске.
- **Безопасность**: без сессии админ‑страницы не открываются (редирект на логин).

## Regression (20–40 минут)

- **Роли/доступы**:
  - админ видит административные функции;
  - пользователь не может выполнять админ‑действия.
- **Валидация форм**:
  - обязательные поля, длины, форматы (email/телефон), “плохие” символы;
  - корректные сообщения об ошибках.
- **Заказы**:
  - расчёт итоговой суммы совпадает с ожиданием;
  - добавление/изменение позиций в заказе не ломает UI;
  - создание заказа сохраняется и отображается в списке.
- **Данные**:
  - таблицы не пустые на ключевых страницах (если стенд с демо‑данными);
  - пагинация/фильтры (если есть).
- **Нефункциональные**:
  - скорость: страницы не “висят”, нет долгих блокировок UI;
  - ошибки не светят stack trace/SQL.

## Full (перед сдачей/релизом)

- **Кросс‑браузер**: Chrome + (по возможности) Firefox/Edge.
- **Адаптивность**: 320px / 768px / 1024px.
- **Безопасность (ручные пробы)**:
  - простые инъекции в поля (`' OR 1=1 --`, `<script>alert(1)</script>`): не должны приводить к XSS/SQL‑ошибкам;
  - прямые ссылки на админ‑страницы без логина — редирект.
- **Отчёты/артефакты**:
  - в `selen/reports/` есть `latest_result.json` и `junit_latest.xml`;
  - в `selen/screenshots/` есть HTML‑сводка `screenshots_summary.html`.
